# Iris Flower Classification

A beginner-friendly Machine Learning classification project using **Logistic Regression** and the built-in Iris dataset from Scikit-learn.

## Features

- Load Iris Dataset
- Explore Dataset
- Train-Test Split
- Logistic Regression Model
- Make Predictions
- Calculate Accuracy
- Generate Confusion Matrix
- Generate Classification Report
- Export Predictions to CSV

## Technologies

- Python
- Pandas
- NumPy
- Scikit-learn

## Machine Learning Workflow

```
Load Dataset
      │
Train-Test Split
      │
Train Logistic Regression Model
      │
Make Predictions
      │
Evaluate Model
```

## Run

```bash
python main.py
```
